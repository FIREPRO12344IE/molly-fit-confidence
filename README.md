# Molly's Confidence Coaching

Create a modern, premium fitness personal-training website for “MR Coaching”, owned by Molly.



The website should feel feminine, welcoming, professional, motivating and clean. Use a soft light pink/cream colour palette with black/dark charcoal text and subtle accents. The design should be mobile-first and work beautifully on phones, tablets and desktops.
